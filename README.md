Attendance Management System
Introduction

The Attendance Management System is a simple application designed to manage and track student attendance efficiently. This project helps reduce manual work and makes it easier to store, update, and retrieve attendance records.

Objectives
To automate the process of marking attendance
To maintain accurate student attendance records
To reduce paperwork and human errors
To provide quick access to attendance data
Features
Add and manage student details
Mark daily attendance
View attendance records
Update or delete records
Simple and user-friendly interface
Technologies Used
Programming Language: (JavaScript)
Frontend: (HTML, CSS)
Backend: (JavaScript)
Database: (MySQL using xaamp)
